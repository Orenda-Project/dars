# Curriculum Planner & Tracker

## What this is

A set of three connected tools that help a teacher plan, execute, and track their entire academic year — from mapping a book to the calendar, to breaking chapters into individual lesson plans, to seeing which Student Learning Outcomes have been covered.

The three tools are:

1. **Syllabus Breakdown** — maps an entire book's chapters across the academic year
2. **Lesson Chunking** — breaks a single chapter into a sequence of typed lesson plans
3. **SLO Tracker** — shows which learning outcomes have been covered based on generated LPs

These tools live on the Dars dashboard and are available to any logged-in user.

---

## Tool 1: Syllabus Breakdown

### What it does

Given a book and an academic year calendar, the teacher (or admin) maps each chapter to a specific block of time across the school year. The calendar is aware of weekends, public holidays, school holidays, and activity days — so only actual teaching days are shown.

The output is a visual year plan: a timeline where each chapter occupies a span of teaching days.

### Who sets it up

An admin populates the initial global curriculum — the default mapping of chapters to the year. Teachers can then fork and edit their own version. For the prototype, there is only one shared version that anyone can edit.

### Data

- **Book** — has chapters in a default sequence (e.g. English Book 5: 12 chapters)
- **Academic calendar** — school year start/end date, with marked-out days (weekends, Eid, Independence Day, winter break, exam weeks, sports day, etc.)
- **Teaching days** — derived automatically from the calendar
- **Chapter mapping** — each chapter assigned a start teaching day and end teaching day, defining how many teaching days are allocated to it

### Two subjects in the prototype

The prototype includes two subjects with static data:

**English (Grade 5)**
- Book: "New Countdown English 5"
- Chapters: 12 (e.g. The Clever Fox, The Lost Kite, A Day at the Farm, …)
- Academic year: April 2026 – March 2027
- Approx. 180 teaching days after removing weekends + holidays

**Mathematics (Grade 5)**
- Book: "New Countdown Maths 5"
- Chapters: 10 (e.g. Whole Numbers, Fractions, Decimals, Geometry, …)
- Same academic year and calendar

### Views

The Syllabus Breakdown has two view modes, togglable by the teacher:

- **Calendar view** — month-by-month grid with chapters shown as colour-coded spans across days. Non-teaching days (weekends, holidays) are greyed out. Gives a visual sense of pacing across the year.
- **List view** — a compact ordered list of chapters with day counts and date ranges. Faster to scan and edit.

Both views reflect the same underlying data. The teacher can switch freely between them.

### Interactions

- **Reorder** — drag chapters to change teaching sequence (list view)
- **Resize** — adjust how many days a chapter gets
- **Mark days off** — add one-off non-teaching days (school trip, exam, etc.)
- **Progress indicator** — chapters where at least one lesson has been viewed show a "started" badge; chapters where all lessons have been viewed show "complete"
- **Editability rule** — chapters that are in the past (all their allocated days have passed) are locked and cannot be reordered or resized

## Tool 2: Lesson Chunking

### What it does

Takes one chapter and a number of lessons, and breaks that chapter into a sequence of typed lesson plans. Each lesson plan is identified by its **LP Type** (skill type), which determines what kind of lesson it is and how it will be generated by LP Assistant.

This module can run standalone (just pick a chapter and say "give me 8 lessons") or be driven by the Syllabus Breakdown (where the number of days allocated to a chapter becomes the suggested number of lessons).

### LP Types

LP types are subject-specific:

| Subject | Available LP Types |
|---|---|
| English | reading, comprehension_word_meanings, comprehension_qa, grammar, creative_writing, revision |
| Urdu | reading, comprehension_word_meanings, comprehension_qa, grammar, creative_writing, revision |
| Maths | concrete, pictorial_and_abstract, word_problems, revision |
| Science | revision |
| GK | revision |

### What the module produces

A **lesson sequence** — an ordered list of lesson slots, each with:

- `lesson_number` — position in the chapter sequence
- `lp_type` — the skill type for this lesson
- `title` — a short descriptive title (e.g. "Reading: The Clever Fox")
- `status` — `planned` | `viewed`

**Important distinction:** Lesson Chunking does not generate lesson plans. It produces the *parameters* of each lesson plan — the LP type, the chapter, the topic text, the relevant pages. The actual LP is only generated when the teacher opens that lesson slot to view it. This means generation is deferred, on-demand, and lazily triggered by the teacher's intent to teach that lesson.

For the prototype, clicking "View Lesson" on any slot shows a static sample LP rather than triggering real generation.

The AI decides how to distribute LP types across the requested number of lessons. For example, a 10-lesson English chapter might look like:

1. Reading
2. Comprehension — Word Meanings
3. Comprehension — Q&A
4. Grammar
5. Reading (second pass / deeper)
6. Comprehension — Q&A
7. Creative Writing
8. Grammar
9. Creative Writing
10. Revision

### Interactions

- **Input** — select subject, select chapter, enter number of lessons (or accept suggestion from Syllabus Breakdown)
- **Generate sequence** — AI proposes the lesson breakdown
- **Edit** — teacher can change LP type of any slot, add/remove slots, reorder
- **View Lesson** — clicking a slot shows the lesson plan. This is the trigger for generation in production; in the prototype it shows a static sample LP.
- **Link to Syllabus** — if coming from Syllabus Breakdown, the chapter and lesson count are pre-filled

## Tool 3: SLO Tracker

### What it does

Shows the teacher which Student Learning Outcomes they have covered so far, and which remain. Coverage is derived from the lesson plans that have been generated — each LP is mapped to sub-SLOs, which roll up to SLOs.

### Data model (static for prototype)

- **SLOs** — a flat list of learning outcomes for a given grade + subject + curriculum authority (e.g. NCP Grade 5 English)
- **Sub-SLOs** — granular observable skills under each SLO (e.g. SLO "Reading Comprehension" → sub-SLO "identifies the main character", "infers meaning from context", …)
- **Topic → Sub-SLO mapping** — each book chapter/topic is linked to the sub-SLOs it addresses
- **LP → Sub-SLO** — inherited from the topic; an LP for a topic covers the sub-SLOs of that topic

### What the teacher sees

- A list of SLOs for their subject, each showing:
  - How many sub-SLOs it has
  - How many have been covered ("covered" = the teacher has viewed/opened the LP for a lesson mapped to this sub-SLO)
  - A progress bar
- Drill down into any SLO to see which sub-SLOs are covered vs. not
- A summary card at the top: "X of Y SLOs fully covered, Z partially covered"
- Filter by chapter to see SLO coverage for a specific part of the book

### For the prototype

SLO data is static. Use a representative sample:

**English Grade 5 — NCP SLOs (sample)**
- R1: Read aloud with correct pronunciation and fluency
  - R1.1 reads with appropriate pace
  - R1.2 uses correct stress and intonation
  - R1.3 reads unfamiliar words using phonics
- R2: Demonstrate reading comprehension
  - R2.1 identifies the main idea
  - R2.2 answers literal comprehension questions
  - R2.3 infers meaning from context
  - R2.4 identifies the main character and setting
- W1: Write grammatically correct sentences
  - W1.1 uses correct punctuation
  - W1.2 applies subject-verb agreement
  - W1.3 uses appropriate vocabulary

**Maths Grade 5 — NCP SLOs (sample)**
- N1: Understand and work with whole numbers
  - N1.1 reads and writes numbers up to 1,000,000
  - N1.2 compares and orders large numbers
  - N1.3 applies place value
- N2: Perform operations with fractions
  - N2.1 adds and subtracts fractions with like denominators
  - N2.2 multiplies a fraction by a whole number
  - N2.3 converts between mixed numbers and improper fractions

## How the three tools connect

```
Syllabus Breakdown
  └── Chapter X allocated N teaching days
        └── Lesson Chunking
              └── Chapter X → N lesson slots, each with an LP Type
                    └── LP Generation (existing Dars feature)
                          └── LP generated and linked to chapter topic
                                └── SLO Tracker
                                      └── Sub-SLOs covered by this topic marked as done
```

A teacher can enter the flow at any point:
- Start with Syllabus Breakdown for a full-year view
- Jump straight to Lesson Chunking for a specific chapter
- Check SLO Tracker at any point to see curriculum coverage
