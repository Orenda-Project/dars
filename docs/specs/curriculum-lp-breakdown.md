# Curriculum LP Breakdown

**Date:** 2026-04-14
**Status:** Planned

---

## Goal

Given a book's topics (linked to SLOs), automatically produce a full curriculum plan of LP stubs that UG LP can generate actual lesson plans from.

---

## Data Model

### 1. `sub_slos`

Granular breakdown of an SLO, authored in the Schema tool and imported here.

| Column | Type | Notes |
|--------|------|-------|
| `id` | uuid PK | |
| `slo_id` | uuid FK → slos | |
| `code` | varchar(50) | e.g. `E.03.A1.01.1` |
| `statement` | text | e.g. "Identifies the main character in a story" |
| `source_id` | int | Schema tool PK |
| `is_active` | boolean | |

### 2. `topics`

Sits under `book_chapters`. A chapter has multiple topics in sequence.

| Column | Type | Notes |
|--------|------|-------|
| `id` | uuid PK | |
| `chapter_id` | int FK → book_chapters | |
| `title` | text | |
| `sequence` | int | order within chapter |
| `source_id` | int | Schema tool PK |

### 3. `topic_sub_slos`

Many-to-many between topics and sub-SLOs.

| Column | Type | Notes |
|--------|------|-------|
| `topic_id` | uuid FK → topics | composite PK |
| `sub_slo_id` | uuid FK → sub_slos | composite PK |

### 4. `curriculums`

A named plan tying together a book, grade, subject, SLO provider, and academic year. A book stays provider-neutral; the curriculum is what pins a book to a specific SLO set (NCP, SNC Punjab, etc.). The same book can have multiple curriculums for different providers.

| Column | Type | Notes |
|--------|------|-------|
| `id` | uuid PK | |
| `name` | varchar(255) | e.g. "Grade 3 English 2025-26" |
| `grade_id` | uuid FK → grades | |
| `subject_id` | uuid FK → subjects | |
| `book_id` | int FK → books | |
| `provider_id` | uuid FK → slo_providers | |
| `academic_year` | varchar(20) | e.g. "2025-2026" |
| `is_active` | boolean | |
| `created_at` | timestamptz | |

### 5. `curriculum_topics`

Ordered list of topics within a curriculum.

| Column | Type | Notes |
|--------|------|-------|
| `id` | uuid PK | |
| `curriculum_id` | uuid FK → curriculums | |
| `topic_id` | uuid FK → topics | |
| `sequence` | int | order within curriculum |

### 6. `curriculum_lp_stubs`

One row per LP to be generated by the AI breakdown module. Each stub becomes a lesson plan.

| Column | Type | Notes |
|--------|------|-------|
| `id` | uuid PK | |
| `curriculum_topic_id` | uuid FK → curriculum_topics | |
| `skill_type` | varchar(50) | e.g. "listening" |
| `cpa_phase` | varchar(50) | e.g. "concrete" |
| `blooms_level` | varchar(30) | e.g. "understand" |
| `sequence` | int | order within topic |
| `status` | varchar(20) | pending / generated / failed |
| `lesson_plan_id` | uuid nullable FK → lesson_plans | set after generation |
| `created_at` | timestamptz | |

---

## Sample Rows (Grade 3 English, Chapter 1 "The Giving Tree")

```
books:               { id: 7, title: "English Grade 3", grade: 3, subject: "English", curriculum: "Punjab" }
book_chapters:       { id: 43, book_id: 7, chapter_number: 1, title: "The Giving Tree" }
topics:              { chapter_id: 43, title: "Characters and Setting", sequence: 1 }
sub_slos:            { slo_id: <NCP SLO uuid>, code: "E.03.A1.01.1", statement: "Identifies the main character in a story" }
topic_sub_slos:      { topic_id: <uuid>, sub_slo_id: <uuid> }
curriculums:         { name: "Grade 3 English 2025-26", grade_id: <G3 uuid>, subject_id: <Eng uuid>, book_id: 7, provider_id: <NCP uuid>, academic_year: "2025-2026" }
curriculum_topics:   { curriculum_id: <uuid>, topic_id: <uuid>, sequence: 1 }
curriculum_lp_stubs: { curriculum_topic_id: <uuid>, skill_type: "listening", cpa_phase: "concrete", blooms_level: "understand", sequence: 1, status: "pending" }
```
