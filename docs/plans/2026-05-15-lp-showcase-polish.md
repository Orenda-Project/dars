# Plan: Make the LP showcase pretty (A + B + naming/UX fixes)

## Context

The showcase is live at `https://dars-fe-stage.up.railway.app/showcase/ali-sipra-2026-05-15` and works — 10 LPs load, navigation works, no errors. But it looks bad because **LP Assistant returns completely unstyled HTML** (bare `<html><h2>…</h2><p>…</p></html>`, no `<head>` styles, no fonts), and the shell has rough edges that make it feel like a one-off page rather than a finished product demo.

The user approved Tracks A + B from the menu plan, plus three concrete fixes:
1. Rename — drop "ali-sipra" from the URL/branding (it's awkward to share a URL with one person's name on it).
2. Group the LP list by something more meaningful than a flat 10-row list.
3. Make each list entry obvious — at-a-glance, what is this LP actually about?

This plan locks in those three asks alongside A + B.

---

## Concrete changes

### 1. Rename: `ali-sipra-2026-05-15` → `lp-showcase`

Short, neutral, future-proof. The URL becomes `https://dars-fe-stage.up.railway.app/showcase/lp-showcase`.

- Move the existing committed directory: `webapp/public/showcase/ali-sipra-2026-05-15/` → `webapp/public/showcase/lp-showcase/`
- Update the landing-page CTA href in `webapp/components/templates/landing-template.tsx`
- Update the gitignore exception in `webapp/.gitignore` (un-ignore `lp-showcase/` instead of `ali-sipra-2026-05-15/`)
- Update the default `--tag` flag in `useful-scripts/generate_showcase_lps.py`

The dynamic route `[tag]` already accepts any tag, so no route changes needed.

### 2. Track A — Style the LP HTML

Inject a shared stylesheet into each LP's HTML at generation time:

- New file: `webapp/public/showcase/_assets/lp.css` (committed). Dars tokens — serif headings (Georgia/Lora fallback), Inter body, ink/parchment/terracotta palette, 1.75 line-height, max-width 720px, generous section spacing.
- Section headings (`h2`) styled as small terracotta uppercase labels with a left rule; `🎯` emoji stripped from h2 text via script preprocessing (don't rely on CSS to hide — cleaner).
- `<h1>` injected at top of each LP: "Grade {N} — {skill}" (script-generated, pulls from spec).
- Q&A `<ul>` styled with answer in `text-dars-muted`, slightly smaller, indented.
- Hairline rules between sections (SLO / Hook / Explanation / Practice / Conclusion).
- `@media print` rules for clean A4 export.

Script changes (`useful-scripts/generate_showcase_lps.py`):
- New `wrap_html(spec, raw_html) -> str` helper: ensures `<!doctype html>`, injects `<head>` linking to `/showcase/_assets/lp.css`, adds `<h1>`, strips `🎯`, wraps body content if it's loose under `<html>`.
- Called from `write_results()` before disk write.

### 3. Track B — Showcase shell polish (+ user's grouping/obviousness asks)

Edits to `webapp/components/templates/showcase-template.tsx` and `webapp/app/showcase/[tag]/page.tsx`:

**Header strip** above two-pane:
- Eyebrow: "LESSON PLAN SHOWCASE"
- Serif title: "Sample lesson plans" (no stakeholder name)
- One-line subtitle: "10 plans generated by Dars · Grade 2 & 5 · English · ICT curriculum"
- Date generated (stat `index.json` mtime, formatted nicely)

**List pane — grouped by Grade, with obvious labels:**
- Two collapsible-looking sections: "**Grade 2** · 5 lesson plans" and "**Grade 5** · 5 lesson plans" with a subtle parchment-mid section header
- Each entry shows, prominently:
  - **Top line**: skill name in bold (e.g. "Reading", "Grammar") — currently buried inside a sub-label
  - **Second line**: topic + page in muted text (e.g. "Journey through text · p. 111")
  - **Right edge**: a small skill icon (inline SVG — open-book for Reading, pen for Creative writing, list for Comprehension Q&A, ABC for Grammar, dictionary for Comprehension w/ meanings)
- Active state: terracotta left border + parchment background (already there, refining the rest)

**Right pane:**
- Header gets a small toolbar: `[Open in new tab ↗]  [Print 🖨]  [Copy share link ⎘]`
  - "Open in new tab" → `/showcase/lp-showcase/lp-NN.html` (deep link to the styled LP standalone)
  - "Print" → `window.print()` on the iframe via postMessage, OR just opens lp-NN.html which is print-styled
  - "Copy share link" → copies the current showcase URL with a `?lp=NN` hash to deep-link to a specific LP
- Iframe loading skeleton — parchment-tinted placeholder rectangles until `onLoad` fires
- Deep-link support: if URL has `?lp=NN`, pre-select that entry on mount

**Mobile (<lg):**
- List pane collapses above the right pane (not side-by-side)
- Within the list, the grade groups stay; entries become horizontal-scroll pills if too long

**Footer:**
- Small line: "Generated by Dars · drs.taleemabad.com" — frames it as a product, not a one-off.
