# Features

One folder per feature under `docs/features/<slug>/`. Each folder has its own `README.md`, `ONRAMP.md` (after plan approval), `01-decision-log.md`, and one or more phase docs. See `dars/.claude/skills/feature/SKILL.md` for the workflow.

The v2 rebuild (`docs/plans/2026-05-15-dars-v2-rebuild/`) predates this convention and stays where it is; new features start here.

## Active

- [core-book-import](core-book-import/README.md) — admin dashboard action to import a taleemabad-core book (`fde_staging`) into Dars: browse Core Books → pick one → background job imports the whole curriculum cell (SLOs → sub-SLOs via vendored Schema breakdown prompt + Claude lp_type → book + chapters with prose sliced per chapter → 1-topic-per-chapter → topic↔sub-SLO + chapter↔SLO mappings). New `import_runs` table + status polling (D-1); scope auto-derived from the core row (D-2); real per-topic breakdown deferred to a fast-follow (D-3); productizes the one-shot `scripts/import_ncp_english_g1.py`. Phase 1 (backend) planned.
- [chapter-planner-engine](chapter-planner-engine/README.md) — _superseded by [chapter-planner-in-dars](chapter-planner-in-dars/README.md) (2026-06)._ The originally-standalone LLM Chapter Planning Engine prototype; its planner core was ported into `server/src/dars/breakdown/` (Phase 1) and wired into break-it-down (Phase 2), and the standalone `dars/chapter-planner-app/` was deleted. Folder kept as historical record.
- [class-today-dashboard](class-today-dashboard/README.md) — new **Today** tab as the default class view in the teacher app: today's date, today's LP/assessment with view + mark-taught, a Covered/Now/Next strip, and a sub-SLO coverage meter. Frontend-only. Phase 1 in flight.
- [ncp-english-g1-seed](ncp-english-g1-seed/README.md) — real NCP curriculum data (English × G1) alongside the synthetic Dars seed: SLOs from `fde_staging.slo_ncpslo`, sub-SLOs via Schema-style breakdown, lp_type via Claude, book 1171 prose from `book.book_text`. Phase 1 in flight.

## Closed

- [exam-periods-and-formative-assessments](exam-periods-and-formative-assessments/README.md) — two additions to the syllabus-breakdown / chapter-planner / calendar subsystem, shipped together: (1) **Exam Periods** + **Breakdown Holidays** — admin reserves exam/holiday date ranges (Eid, etc.) on a global Syllabus Breakdown; both excluded from teaching-day derivation in the admin display and inherited into every class plan (`exam_periods` + `breakdown_holidays` tables, unioned into `compute_teaching_days`). (2) **Formative Assessments** — the Intelligent Chapter Planner decides where FAs go (`PlanUnit.slot_type`), persists them as `class_assessment_slots`, and an FA slot produces **Exam Generator inputs** (default per-subject config, `generation_type='class_assessment'`) driving the existing exam-generation path on demand. Shipped 2026-06-10 via PR #136 (exam periods + holidays) + #137 (FA planner) + #138 (FA exam inputs). Notable: #138 fixed a latent broken-join bug in the exam-slot loader (D-18 — CST has no curriculum_id/grade_id). Follow-ups, all out of original scope: Summative Assessments (D-16, the upstream work the dynamic planner waits on), per-slot editable FA config (D-10), and a `/today` `exam_status` field for the Today-card FA button.
- [book-viewer](book-viewer/README.md) — admin dashboard book detail page in two views off one fetch: **Rendered** (book metadata → expandable chapters with linked SLOs + per-chapter OCR text → topics with topic_text + sub-SLOs) and a **Raw JSON** collapsible (default off) dumping the full book tree with OCR. Backend `GET /api/v2/books/{id}/tree` (5-query no-N+1 assembly, D-2); enriches the existing `/dashboard/curriculum/books/[book_id]` page (D-6). No schema change. Shipped 2026-06-04 via PR #121.
- [intelligent-chapter-planner](intelligent-chapter-planner/README.md) — replaced the deterministic chapter-plan core with an **LLM-driven planner**: given a chapter, its SLOs/sub-SLOs, and the period count, it emits LP units (LLM-defined, may merge/split book topics — inputs to the LP Assistant) + Formative Assessments, with the existing heuristic planner kept as a validator-gated fallback. New `class_lesson_slot_topics` join table; wired behind the existing `/plan` endpoint; FA + LPs only (no summative). `PlannerLLM` interface — API-key backend in prod, Agents SDK in dev (D-10). Shipped 2026-06-03 via PR #108. Follow-ups: `dars-icp-json-retry` (D-14), `dars-grade-int-parse`.
- [syllabus-breakdown-and-teacher-chapter-plan](syllabus-breakdown-and-teacher-chapter-plan/README.md) — ground-up re-architecture: renamed Chapter Breakdown → **Syllabus Breakdown** (admin/global, chapter→date-range only; `syllabus_breakdowns`/`syllabus_chapters` tables); dropped admin slots/fork/auto-build/realize and all org/class scope; moved the **Chapter Plan** to a teacher-app "break it down" flow where slot count = real teaching periods in the chapter's date range (`compute_teaching_days`). Supersedes `chapter-breakdown-and-plan`. Shipped 2026-06-02 via PR #101 (rename) + #102/#103 (demolition + migration hotfix) + #104 (teacher Chapter Plan).

- [chapter-breakdown-and-plan](chapter-breakdown-and-plan/README.md) — split breakdown authoring into two explicit dashboard actions: **Chapter Breakdown** (order chapters + explicit calendar date ranges, derived teaching days, advisory overlap/gap warnings) and **Chapter Plan** (manually break a chapter into typed slots with page ranges; auto-build demoted to an optional per-chapter "Seed plan"). Two additive schema deltas. Shipped 2026-06-02 via PR #98 (phase 1) + #99 (phase 2).

- [class-timeline-view](class-timeline-view/README.md) — replaced the teacher app's separate Lessons + Assessments tabs with one **unified, dated timeline**: lessons + assessments interleaved by position, stamped with projected dates from the backend projector, grouped by chapter, with a "you are here" marker, kind filter, quiet generation status, and conflict/overflow warnings. New `GET /csts/{id}/timeline` endpoint + Timeline tab. Shipped 2026-06-01 via PR #95 (backend) + #96 (frontend).

- [breakdown-slot-editing](breakdown-slot-editing/README.md) — org-admin per-slot editing (slot_type / lp_type / topic_id) + add/delete in draft org breakdowns. Shipped 2026-05-20 via PR #84.
