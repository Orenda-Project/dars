# Glossary

Only terms specific to the NCP-English-G1 seed effort. Terms from the v2 rebuild plan (`docs/plans/2026-05-15-dars-v2-rebuild/00-glossary.md`) are not redefined here.

| Term | Definition |
|---|---|
| **NCP** | National Curriculum of Pakistan — the official curriculum framework. Distinct from "Dars Curriculum" (Taleemabad's in-house) and any other curriculums seeded in lookups. |
| **NCPSLO** | The Django model in `taleemabad-core/apps/slo/models.py` holding top-level NCP SLOs. Has a `ncp_slo_id` field (e.g. `A1-02`) which is the canonical code. |
| **Sub-NCP-SLO** | A finer-grained learning step under an NCPSLO. **Not** a Django model — these are LLM-generated by Schema's breakdown service and live only in Schema's output. Codes look like `A1-02-a`. |
| **fde_staging** | The live Postgres database for the taleemabad-core staging environment. Source of truth for NCPSLO rows + book_library tables. Read-only access from a developer workstation via SQL — see `D-9`. (The local file `db_dumps/fde_staging_schema.dump` is a snapshot of the same data but is not used by this feature.) |
| **Schema repo** | `/home/hataf/taleemabad/Schema/` — the SLO breakdown tool. Used here only to generate sub-NCP-SLOs and topic↔sub-SLO mappings once, offline. |
| **Frozen fixture** | A JSON file committed under `server/src/dars/seeds/ncp_english_g1/` produced by the offline extraction pipeline. The runtime seed reads these as static inputs; nothing is generated at boot. |
| **Extraction pipeline** | A one-shot script (lives in `scripts/extract_ncp_english_g1.py`) that hits `fde_staging` + Schema and writes the frozen fixtures. Not run on Railway; run locally by a developer. |
| **lp_type derivation** | Mapping from NCPSLO `domain` / `language_skills` fields → the dars `lp_type` enum (`reading`, `comprehension_word_meanings`, `comprehension_qa`, `grammar`, `creative_writing`). NCPSLO has no native `recommended_lp_type` field. See `D-2`. |
| **Aisha demo** | The existing synthetic tenancy: 1 org "Aisha Demo Org", 1 school, 1 G1-A class, 1 teacher. Untouched by this feature. |
