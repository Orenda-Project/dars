Learning Objectives by Grade

GradeLearning Objective
Grade 1Students will be able to identify and write the names of familiar objects (cat, dog, bat) by matching pictures to words. Ground in textbook page 10.
Grade 2Students will be able to write 2-3 simple sentences describing a picture using given adjectives (big, pretty, calm). Ground in textbook page 133.
Grade 3Students will be able to identify and use commas in a list of actions or items. Ground in textbook page 32.
Grade 4Students will be able to answer comprehension questions based on a text and create anagrams. Ground in textbook page 39.
Grade 5Students will be able to count syllables in words and write a short paragraph using multi-syllable words. Ground in textbook page 15.
